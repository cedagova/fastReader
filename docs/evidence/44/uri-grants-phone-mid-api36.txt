# What FastReader is allowed to keep, Phone_Mid_API36

Taken while `backup-check.epub` was open through the share sheet (session-only)
and `the-lighthouse-keeper.epub` had been added earlier through the library
picker. Same package, same moment, three grants: the difference between them is
the whole of REQ-103's two paths.

- `msf:71`, `msf:72` — handed over by the Files app. `persistable=0x0
  persisted=0x0`: the platform never offered a keepable grant, so these are the
  session-only path. Nothing about them survives the process.
- `msf:73` — the same file, added later through FastReader's own picker.
  `persistable=0x3 persisted=0x1`: a grant that outlives the process, which is
  why that book has a library row.

# What the Files app actually sends

Neither intent carries FLAG_GRANT_PERSISTABLE_URI_PERMISSION (0x40). That is why
an "Open with" from the Files app takes the session-only path: the app cannot
take a grant it was not offered.

ACTION_VIEW, tapping the book in the Files listing:
  Intent { act=android.intent.action.VIEW dat=content://com.android.providers.downloads.documents/document/msf%3A73 typ=application/epub+zip flg=0x30000003 xflg=0x4 }
  launchedFromPackage=com.google.android.documentsui

ACTION_SEND, sharing it from the same app:
  Intent { act=android.intent.action.SEND cat=[android.intent.category.DEFAULT] typ=application/epub+zip flg=0x13000001 xflg=0x4 cmp=com.cedagova.fastreader/.MainActivity clip={application/epub+zip {U(content)}} (has extras) }
  launchedFromPackage=com.google.android.documentsui
