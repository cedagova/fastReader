# Evidence (historical record)

Proof recorded while issues were delivered: screenshots, device transcripts,
APK and manifest checks, one directory per issue number (`docs/evidence/<n>/`).

- **Historical, not current.** Each directory is what was true at that
  issue's head. Paths, class names and module names in it may have moved
  since; the current map of the code is
  [docs/architecture.md](../architecture.md).
- **Not part of any copy.** A new client takes the libraries through the copy
  set in [docs/library-consumption.md](../library-consumption.md), which
  names no path under `docs/`.
- **Kept, not deleted.** Issues, PRs and current docs link here, and removing
  the files from `main` would not shrink the repository's history.
