What this proves (#117 acceptance, AD-27): the increment that makes FastReader
upload a book for the first time changes NONE of the release gate's proofs. The
signed release APK still asks for exactly the internet permission plus Android's
own broadcast self-permission, still allows no cleartext, still installs on
Android 8.0+, and still carries 1.7.0 / versionCode 9 — this leaf bumps nothing
(AD-28: 1.7.0 is unreleased and its notes are edited in place).

That the permission set is unchanged is the load-bearing line. The transfer this
leaf adds goes over a second HTTP client inside `:reader-library`
(PublicationTransferClient), and a second client is exactly the kind of change
that would otherwise drag in a permission or a cleartext exemption. It does not:
the module's manifest is still empty, and the bytes go to an https signed URL.

scripts/release.sh itself is untouched by this leaf. Gradle's build output is
elided; everything below is the script's own verification, verbatim. The
certificate digest is the public pinned value already recorded in
docs/release.md and in scripts/release.sh. Nothing here carries a token, a
backend value, an account code, an email address or a request secret.
