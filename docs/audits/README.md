# Audits (historical record)

Audit dossiers as they were completed. `A83-android-client-auth/` is the audit
of the Android client's authentication that led to `:reader-auth`; its
findings were delivered through the issues it names. Later audit dossiers
(such as A197) live on their own dossier PRs.

Paths and line numbers in a dossier resolve against the baseline commit it
names, not against `main`. The current map of the code is
[docs/architecture.md](../architecture.md).
